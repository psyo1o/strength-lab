# 강도 1–5 사다리 실측

기준은 `9707cfc`이다. 모델은 `gpt-5.4-nano`이고, 입구는 `regenerate-week`이다. 이 입구는 `COACHING_PIPELINE`과 `LONGITUDINAL_PLANNING`을 끈다. DB는 2099 임시 파일만 썼다. `MONTH_PLAN_MODEL_KEY`는 설정되어 있다. 값은 적지 않는다.

한 세션의 뼈대는 하나다. 같은 컨디셔닝 호출이 `levels` 1–5의 사다리 동작, 라운드, 수량, Rx 무게, 캡을 낸다. 코드는 고른 동작이나 숫자를 바꾸지 않는다. 횟수 시간은 사다리 `rep_cost`로 계산한다. 추정 완료는 캡 이하이고, 캡은 그 강도의 최소 이상이다. 캡 ±25%, 추정 ≥ 최소, 치퍼 90%는 그대로다. 인접 쌍은 사다리 단계가 하나 이상 달라지거나 추정 총작업량(횟수×rep_cost×부하계수)이 1.10배 이상이면 통과다. 4와 5도 같다. 둘 다 아니면 그 높은 레벨만 숨기고 관리자 카드에 이유를 둔다. 무게나 횟수로 올려도 된다. 고난도 동작은 필수가 아니다. 바로 아래 레벨이 숨김이면 그 칸은 비교 기준이 아니다. 기본 3이 실패하면 그 날은 실패다. 존 2는 레벨을 나누지 않는다. 엔진 탭의 강도 선택은 표시만 바꾼다. 기본은 3이다. 회원 문장에는 파운드 Rx만 적고, 카탈로그 킬로그램은 동작 필드에 남긴다.

## 모킹

`tsc --noEmit`은 통과했다. `vitest`는 95개 파일, 623개 테스트가 통과했다. 모킹은 실측이 아니다. 관리자 카드의 1–5 비교는 화면 클릭 없이 상태 데이터와 테스트로 확인했다.

## 4↔5

통과한 4↔5 쌍 중 용량이 같은 쌍은 0이다.

| 구분 | 보통 | 고피로 | 합 |
|---|---:|---:|---:|
| 둘 다 통과 | 0 | 1 | 1 |
| 동작 변경으로 상승 | 0 | 1 | 1 |
| 작업량으로 상승 | 0 | 0 | 0 |
| 동작과 작업량 둘 다 | 0 | 0 | 0 |
| 레벨 4는 통과, 레벨 5는 숨김 | 4 | 4 | 8 |
| 레벨 4가 숨어서 5를 비교하지 않음 | 16 | 15 | 31 |

고피로 2099-11-02 목요일 치퍼 1일만 4↔5가 동작으로 올랐다. 레벨 4의 턱걸이는 Chest-to-bar이고 레벨 5는 Bar Muscle-up이다. 단계는 하나 차이이다. 보통 4주에서 레벨 4가 통과한 4일은 레벨 3보다 작업량으로 올랐고, 레벨 5는 그 용량과 같아서 숨겼다. 레벨 4가 숨은 날은 레벨 5를 4와 비교하지 않는다. 그 날의 레벨 5 용량은 레벨 3과 같다. 보통 16일, 고피로 15일이다.

## 샘플 날 2099-09-07 월요일 회원 화면

보통 1주의 월요일 For Time이다. 문장은 회원 화면과 같은 `renderMetconLine`이다. 숨긴 강도를 고르면 회원 화면은 통과한 강도 3이다. 저장된 하루 블록은 웜업 12, 메인 30, 보조 17, 메트콘 12, 추가 15, 쿨다운 4로 90분이다. 강도 1을 고르면 메트콘 블록이 16분이 되고 하루 합은 94분이다.

- 강도 1: `3라운드 For Time · 캡 16분 / Row Erg 25cal / Dumbbell Thruster 21회 (50/35 lb) / Burpee 20회` — 944초, 캡 960초. 스러스터는 덤벨 단계다.
- 강도 2: 숨김. 사다리 단계도 작업량 10%도 없다. 회원 화면은 강도 3과 같다.
- 강도 3: `3라운드 For Time · 캡 12분 / Row Erg 15cal / Barbell Thruster 16회 (95/65 lb) (스케일 45/35 lb · 11회) / Burpee 17회` — 720초, 캡 720초.
- 강도 4: 숨김. 사다리 단계도 작업량 10%도 없다. 회원 화면은 강도 3과 같다.
- 강도 5: 통과. 회원 문장은 강도 3과 같다. 720초, 캡 720초. 레벨 4가 숨김이라 4↔5 비교는 하지 않았다.

수요일 존 2와 일요일 휴식은 레벨이 없다.
