# 통합 감사 결과

2099 임시 DB, 플래그 끔, `gpt-5.4-nano`, W1 `2099-07-06`만 실제 모델로 여덟 번 돌렸다. 채택된 주는 없다. 호출 171, 토큰 1519157. HTTP 429는 없다. 프로브 8회 상한에 닿아 멈췄다. 한 주도 채택되지 않아 연속 4주는 돌리지 않았다. 병합, 배포, 운영 데이터는 건드리지 않았다. 유사도 임계값은 4다. 검사 기준은 낮추지 않았다.

## 장비

사용자 박스 목록이나 관리자 보유 목록은 없다. 세션 장비는 `data/movement-catalog.json`의 동작으로 채우고, 화면과 제휴 안내에만 쓴다. 모델이 낸 장비 배열은 덮어쓴다. 장비 누락과 장비 불일치는 세션, 복구, fallback, 헤드를 거절하지 않는다. 박스 보유 비교로 되돌리는 분기는 없다. 카탈로그 값이 표시 enum에 없으면 목록에서 빠지고, 그것으로 거절하지 않는다. 유사도 특징의 `equipment`는 그대로다.

단위가 빈 카탈로그 키는 0개다. `fan_bike`, `assault_bike`, `echo_bike`는 `cal`이다. `bike`, `bike_erg`는 `cal`과 `m`이다. `kettlebell`, `abs`, `free_accessory`는 `reps`다. 새 단위는 만들지 않았다. 단위가 하나인 동작에 정수만 오면 그 단위로 읽는다. 단위가 둘 이상이면 숫자를 단위로 바꾸지 않는다.

## 고친 것

아직 쓰지 않은 훈련일은 자극과 유사도 비교에서 뺐다. 재시도는 겹친 이웃 날과 점수 4 이상인 날의 실제 세션을 `overlap_sessions`로 받는다. 형식, 시간, 동작 key와 수량, 자극, 패턴, 겹친 요소가 들어가고, 그 세션과 다른 형식, 자극, 동작으로 짜라고 적는다. 범위 밖 수량은 그 단위와 다른 허용 범위를 함께 적는다. 주간 `why_ko`, `focus`, `scheme_note`, `adjustment_ko`는 최종 주와 같은 한국어 비율 0.7로 거절한다. 비율과 재시도 상한은 그대로다.
