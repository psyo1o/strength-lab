# 표준 동작 카탈로그 협의

모킹 규칙과 2099 한 주 프로브를 다음 협의에 넘긴다. 운영 주 `2026-10-05`, `2026-10-12`의 사실이 아니다. 모킹 통과를 실제 칸 수정이나 주 채택으로 쓰지 않는다. 비교 기준은 Phase 1 최종 검증의 W1이다. 호출 21, 토큰 88052, 화·금 미해결, fallback.

## 둔 계약

기준 파일은 `data/movement-catalog.json` 138개, `0.4.0-draft`다. 컨디셔닝 프롬프트는 `conditioning-coach-v3`, 헤드는 `head-coach-v7`이다. 파이프라인 스탬프는 `coaching-pipeline-v6` 그대로다.

모델이 고르는 동작은 `movement`, 정수 `amount`, `unit`, `load`다. 화면 수량은 표시 문자열 `amount`다. 코드는 key 존재, 허용 단위, 닫힌 범위 이탈만 본다. null, 한 숫자, 주석 범위는 범위 검사하지 않는다. 범위를 만들지 않는다. Rx는 프롬프트의 참고이고 같아야 하는 값이 아니다.

헤드의 라이브 목록은 날짜, 블록, `catalog_key`, 칸(`movement`/`amount`/`unit`/`load`), 새 값이다. 서버는 그 칸만 쓴다. 예전 `action` 목록은 파서가 받아 모킹이 유지된다. 복구의 라이브 스키마는 `cells`다. 세션 전체를 돌려주는 복구는 `recoveryDrift`를 탄다.

`squat`→`back_squat`, `clean`→`squat_clean`, `snatch`→`squat_snatch`는 제안값으로 연결한다. 제안 대상이 카탈로그에 없으면 기존 key를 유지한다. `jerk`와 `air-bike`는 새 동작으로 묶지 않았다.

## 모킹

56파일 375테스트, `tsc --noEmit` 통과. 모델 호출 0. 더블 언더 `60cal`은 전문 코치를 다시 부르기 전에 거절된다. 수량 칸은 그 칸만 바뀐다. 세션 전체를 바꾸고 형식까지 건드리면 거부된다.

## 실제 한 주

`gpt-5.4-nano`, 플래그 끔, W1 `2099-07-06`, 임시 DB `/tmp/movement-catalog-phaseb.db`. 첫 호출은 429가 아니었다. 프로브 코드는 `2bed197`이다.

주는 활성 모델 주가 아니다. `week_status` FAILED, `generation_source` fallback, `final_status` FINALIZE_WITH_WARNING. 모델로 남은 날은 5/6, 미해결은 수요일이다. 모델 호출 21, 토큰 143601. 143601은 그 주 로그의 `total_tokens` 합이고 실패한 수요일 컨디셔닝 35576을 포함한다.

직전과 나란히 두면 호출은 21로 같고 토큰은 88052에서 143601이다. 미해결은 화·금에서 수요일로 바뀌었다. 주 채택은 두 번 다 아니다. 직전 헤드는 편집 목록을 냈고, 이번 헤드는 `BLOCK`과 빈 목록이다. 칸 수정 채택은 두 번 다 없다. 목록 준수는 두 번 다 미검증이다.

이번 채택 세션은 월 푸시업 15·링 로우 12, 화 루마니안 데드리프트 20·로잉 20cal, 목 에어 스쿼트 20·버피 10, 금 로잉 12cal·키핑 풀업 6, 토 행 파워 클린 6·행 파워 스내치 6이다. 수요일 최종 처방은 null이다. `load`는 저장되지 않았다.

수요일 복구는 `toes_to_bar` 수량 셀을 냈으나 채택되지 않았다. 원래 오류는 `pullup_bar` 누락이고, 붙은 뒤의 기록 오류는 빈 `key`다. 그 프로브 뒤에 셀 형태 행은 수량을 숫자로 남기고 `key`를 채우게 했다. 모킹만 확인했다. 모델을 다시 부르지 않았다.

`judgeWeek`는 저장된 `plan_json` 진단이다. `ok` false, `rule_break`. `too_similar`가 아니다. 승인에 묶지 않았다. 직전도 `rule_break`였다.

직전 주 `2099-06-29`의 호출 20과 토큰 190142는 W1에 더하지 않는다. 월 행 토큰은 null이다. `2099-07-01` 방법은 `ACCUMULATION`이다. 직전 검증의 그 달은 `531`이었다.
