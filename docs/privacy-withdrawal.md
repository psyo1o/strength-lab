# 탈퇴와 개인정보

탈퇴는 계정을 지우지 않는다. 운동 기록은 계정 번호로 남기고, 사람을 알아보는 값은 지운다.

## 지우는 값

- 이메일. `withdrawn-<계정 번호>@deleted.invalid`로 바꾼다.
- 이름, 생년월일, 성별, 거절 사유.
- 현재 프로그램, 마지막 세션.
- 비밀번호 해시. 로그인할 수 없는 값으로 바꾼다.
- 세션과 비밀번호 재설정 토큰.

역할은 회원으로 두고, 상태는 `withdrawn`이다. 관리자 권한은 끈다.

## 남기는 값

세트 기록, WOD 기록, 수업 기록, 1RM은 계정 번호만 붙어 남는다. 감사 로그에는 이름과 이메일을 넣지 않고 `pii`가 `deleted`라는 표시만 남긴다.

## 막히는 경우

마지막 관리자는 스스로 탈퇴하거나 다른 관리자가 탈퇴 처리할 수 없다. 다른 관리자가 한 명 더 생긴 뒤에만 된다.

탈퇴한 계정은 다시 로그인하거나 승인할 수 없다. 개인정보를 되돌리려면 탈퇴 전 데이터베이스 백업이 있어야 한다.
